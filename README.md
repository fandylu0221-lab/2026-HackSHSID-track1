# Class Schedule Builder

A Python program that builds a school timetable. It places every student into classes, puts each class in a room, and keeps the walking time low.

## What it does

You enter the students and the courses they take. The program then:

1. groups students into classes (up to 25 students per class)
2. puts the classes into the 7 periods of the day
3. gives each class a room
4. prints the master timetable and the timetable for each student

It also prints the total walking score.
